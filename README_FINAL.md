# ABXE — Complete Development Build

This project is an Android-ready ABXE app built around the supplied ABXE character image.

## Included
- Mobile-first Android WebView shell
- ABXE character preserved as the supplied asset
- Adaptive challenge selection
- 20 puzzle seeds across logic, lateral thinking, observation, deduction and word challenges
- Free-form answer evaluation locally
- Optional secure HTTPS backend hook for richer conversational evaluation
- XP, levels, streaks, best streak
- Daily challenge
- Local memory of mistakes and performance categories
- Achievements
- Arabic/English direction toggle
- Optional device speech feedback
- Settings and local reset
- Offline/local fallback

## Important
This is a complete development project, not a claimed prebuilt APK. To produce an installable APK, build this Android project with Android SDK/Gradle.

If a real remote conversational service is connected, keep its secret key on the server. Never ship provider secret keys inside the APK.
